# ビジネスとしてのシンガポール

{{< photo src="S__116269069_0.jpg" alt="夜のマリーナ・ベイ越しに見るマリーナベイ・サンズとマーライオン" caption="ジュビリー・ブリッジから望むマリーナ・ベイの夜景" >}}

振り返ると、初めてシンガポールを訪れたのは2017年。インドと同じく、こちらも9年の時を経ての再訪となりました。
今回は仕事での訪問でしたが、第一印象は「勤勉」。そして「整然」「規律」という言葉がよく似合う国だなと感じました。国民性と言ってしまうには僕の見ている世界が狭すぎるかもしれませんが、決められたルールの中で最大限に尽力する姿には、少し日本に通じるものを覚えます。

一方で、既存の枠に囚われやすく、前例踏襲で保守的な一面があるとも感じました。これはソフトウェアエンジニアリングにおいては少し致命的で、自由な発想からゼロイチを生み出すような文化は育まれにくそうです。SIerは育っても、スタートアップのようなアグレッシブな動きは限定的だろうなと想像しました。もちろん、それが悪いというわけではなく、こうした文化や風土を理解した上でいかに協働するかが重要なのだと思います。

## こぼれ話: Car Pool制度と子どもたち
僕は少しだけシンガポールに縁があるようで、両親が新婚旅行で訪れた場所でもあります。子どもの頃にその時の話をよく聞いていたのですが、特に印象的だったエピソードがあります。

当時、車で移動する際に「わざと見知らぬ子どもを乗せて走る」という慣習があったそうです。今になって調べてみると、これは「エリア・ライセンス・スキーム（ALS）」という渋滞緩和のための交通規制によるものでした。「乗用車に4人以上が同乗（Car Pool）していれば通行料が無料になる」という特例があったため、車に乗せてもらうことでお小遣いをもらう子どもたちの“バイト”が成立していたようです。今となっては信じられないような面白い制度ですね。

# 日本人はどう見えているか
ホテルのスタッフから「あなた、日本人でしょう？」と声をかけられました。立ち振る舞いや身なりから推測したのだと思います。
そのとき感じたのは、インターナショナルな環境だからこそ「どう立ち振る舞うか」が非常に大切だということです。自分が不利益を被らない範囲で、日本の良き文化や考え方、所作を大切にし続けたいと改めて思いました。

# シンガポールは多民族国家である
インドやインドネシアなどから多くの労働者を迎え入れ、国の基盤を支える人材として重用しているシンガポール。国民はより単価の高い仕事にシフトし、インフラや現場の仕事を外国人に頼る構造が確立されています。日本ではなかなか難しいモデルですが、発展のフェーズに応じた役割分担のあり方として非常に示唆的でした。

# 滞在体験: Maxwell Reserve Singapore
今回は「Maxwell Reserve Singapore, Autograph Collection」に宿泊しました。「その土地の歴史やストーリーを感じられる滞在」をコンセプトにしており、古い建築を活かした趣のあるホテルでした。イギリス植民地時代の展示品なども飾られており、非常にユニークです。

客室はややコンパクトでしたが、オーダー制のラウンジサービスが新鮮で快適でした。とはいえ、次回訪れる機会があれば、また別のホテルも試してみたいなと思います。

# ユニークであることの価値
少しポエミーな話になりますが、人生とは時間の経過とともに「自分をユニークにしていく旅路」なのだろうと思っています。

最初は誰もがマジョリティの中にいますが、何かを突き詰めていくうちに、気づけばマイノリティになっていく。そうすると、まるごと真似したくなるようなロールモデルは減っていき、「この人のこの部分が好き」「この人のここを学びたい」と切り取って参考にするようになります。

だからこそ、自分にはない要素を持っている友人や同僚は本当に貴重で、大切にしたいと感じます。そう考えたとき、日本という国自体も世界の中で十分にユニークであり、それだけで大きな価値があるはずです。このアドバンテージを使わない手はないなと改めて感じました。

# 外国で暮らすことについて
今回の滞在では、海外で暮らす同期や友人に会うことができました。日本人がグローバルな舞台で活躍し、プレゼンスを発揮している姿を見るのはとても誇らしい気持ちになります。

自分自身も過去に1年間アメリカで生活した経験がありますが、「強く希望して長く住み続けたい」とまでは思いませんでした。これは自分のインターナショナルさの限界を知ると同時に、自分がどれだけ日本を好きかを実感した瞬間でもありました。

今回のシンガポール訪問は、海外で戦う日本人への尊敬を深めると同時に、自分の人生にどう取り入れていくかを自問自答する良い機会になりました。
余談ですが、日本人が海外に行くときの[絶妙な感覚を表現した面白いコメディの動画](https://www.instagram.com/reel/DUEP-1wiRtF/?stkn=NnpsczU4dm82N2Vu)があるので、よかったら見てみてください笑 コメディから日本の文化を発信してくれる存在は素敵です。


# 改めて日本のために何ができるか考えた
今のところ、僕は「日本で暮らすこと」の価値をかなり高く評価しています。自分が日本人だからという感情的な理由だけでなく、客観的に見ても日本が世界の中で稀有でユニークな存在だからです。

「そんな日本のために自分は何ができるか」についてAIと議論してみたのですが、行き着いたのは「しっかり稼ぎ、特に外貨を稼ぎ、税金を納め、国内で消費する」という、一周回ってごくシンプルで本質的な結論でした。

振り返ってみると、これまでは「自分の年収に占める外貨の割合」や「自分がどれだけ納税しているか」を定量的な指標として意識したことは少なかったように思えます。これからは「年収」「外貨比率」「納税額」を一つの指標とし、行動指針として「円だけでなく、ドルを稼ぐこと」を意識していこうと思いました。


# まとめと展望
シンガポールがAPAC（アジア太平洋地域）における重要なビジネスハブであり続けることは間違いありません。一方で、インドで感じたような「若者がギラギラとしのぎを削る熱気」とは異なる雰囲気でした。陽気なタクシー運転手に勝手に観光案内されることもなければ、道路の真ん中に牛がいて停車することもない、成熟した都市です。

今回どこか物足りなさを感じたのは、国もチームもすでに高いレベルで完成されており、ルーチンワークの中に組み込まれている印象があったからかもしれません。加点法ではなく、減点法の世界は世の中を少しだけ窮屈にします。つまり、「ここからの爆発的な伸びしろ」を感じにくかったのだと思います。

もちろん、それだけ整っていて安全で素晴らしい国であることは間違いありません。それぞれの国の成熟度や役割の違いを体感できた、非常に実りある出張となりました。
